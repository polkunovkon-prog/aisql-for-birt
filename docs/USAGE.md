# Использование (этап M1)

На этом этапе плагин — **чат с локальной моделью**: помощник, которого можно
спрашивать про BIRT и проектирование отчётов. Создание самих отчётов появится
на следующих этапах (см. `ROADMAP.md`), поэтому чат — это «мозг» будущего
конструктора, уже подключённый к вашему серверу модели.

## Панель «ИИ-конструктор отчётов»

Открыть:

- `Window → Show View → ИИ для BIRT → «ИИ-конструктор отчётов»`;
- в перспективе BIRT «Отчёт» (`Window → Perspective → Open Perspective → Отчёт`)
  панель добавляется в правую область рядом с Outline.

Как пользоваться:

1. введите вопрос в нижнее поле;
2. отправьте — кнопкой **«Отправить»** или **`Ctrl+Enter`**
   (обычный Enter переносит строку);
3. ответ появится в ленте выше; пока модель отвечает, кнопка отправки заблокирована,
   внизу виден статус;
4. **«Очистить чат»** сбрасывает историю диалога;
5. **«Настройки…»** открывает страницу настроек подключаемого сервера.

Примеры вопросов для проверки:

- «Что такое параметр отчёта в BIRT и как его использовать?»
- «Чем отличается Grid от Table в BIRT?»
- «Какие элементы отчёта нужны для простого списка пациентов?»

## Настройки

`Window → Preferences → «ИИ-конструктор отчётов (BIRT)»` (или кнопка «Настройки…» в панели):

| Поле | Смысл |
|---|---|
| Адрес сервера (…/v1) | адрес OpenAI-совместимого сервера |
| Модель | идентификатор модели, например `ornith-ai/Ornith-1.5-35B-A3B-GGUF` |
| Ключ доступа | токен; хранится в файле настроек с правами 600 |
| Температура | «свобода» генерации: 0 — строго, 1 — смелее |
| Таймаут запроса | секунд на один ответ (тяжёлые вопросы — десятки секунд) |
| Ограничение ответа | `0` — не ограничивать |
| Системная инструкция | роль/стиль ответов модели |
| Журнал аудита | включение записи в `~/.ai-birt/ai-birt-audit.jsonl` |

**«Проверить соединение»** обращается к серверу и пишет результат рядом с кнопкой:
«Связь есть. Моделей на сервере: N; выбранная модель найдена» — либо причину
ошибки. Проверка использует значения полей, сохранять настройки не обязательно.

Кнопка **«Restore Defaults»** возвращает значения по умолчанию.

## Файлы на диске

- `~/.ai-birt/ai-birt.properties` — настройки (можно править вручную);
- `~/.ai-birt/ai-birt-audit.jsonl` — журнал аудита.

Изменения в файле настроек подхватываются без перезапуска Eclipse.

## Ограничения этапа M1

- **отчёты пока не создаются** — это консультативный чат; сборка `.rptdesign`
  через BIRT Design API — этап M2;
- ответ печатается целиком после готовности (без потоковой печати по словам);
- история хранится, пока открыта панель (закрытие вида сбрасывает историю);
- обслуживается одна модель (без выбора из списка в интерфейсе).

## Что происходит при ошибках

Все ошибки показываются в ленте чата красным с понятным текстом:

- `Не удалось подключиться…` — сервер выключен или недоступен;
- `HTTP 401 …` — неверный ключ (проверьте `llm.token`);
- `HTTP 404 …` — проверьте адрес (`llm.baseUrl`) и модель;
- `Сервер не ответил за N с` — увеличьте таймаут или повторите;
- `Ответ сервера не является JSON…` — сервер отвечает не как OpenAI API
  (проверьте, что адрес указывает на `/v1`).
