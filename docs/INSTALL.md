# Установка и удаление

Кратко: собрать, установить, запустить Eclipse. Подробности и диагностика — ниже.

## 1. Сборка

```bash
./releng/build.sh
```

Скрипт компилирует бандлы `com.aisql.birt.core` и `com.aisql.birt.ui` компилятором
JDK 8 против jar-ов установленного Eclipse и складывает результат в `dist/bundles/`.

Переменные (если каталоги отличаются от стандартных на этой машине):

- `ECLIPSE_HOME` — каталог Eclipse (по умолчанию `/home/pka/eclipse`);
- `JAVAC`, `JAR` — компилятор/упаковщик (по умолчанию Temurin 8
  `/home/pka/opt/jdk8u504-b01/bin`).

## 2. Установка

```bash
./releng/install.sh
```

Скрипт **не требует root** (Eclipse в домашнем каталоге) и делает следующее:

1. проверяет окружение и что Eclipse закрыт — работающий экземпляр при выходе
   перезапишет кэши, и установка «не увидит» новых бандлов;
2. копирует jar-ы в `<Eclipse>/aisql/plugins` (прежние версии плагина удаляются);
3. регистрирует бандлы в
   `<Eclipse>/configuration/org.eclipse.equinox.simpleconfigurator/bundles.info`:
   записи плагина перезаписываются, чужие строки не трогаются; перед правкой
   сохраняется копия файла (`bundles.info.aisql-backup-…`);
4. сбрасывает кэши Equinox (`configuration/org.eclipse.osgi`,
   `configuration/org.eclipse.core.runtime`) — без этого при смене версии
   Equinox может переиспользовать старые данные бандлов;
5. проверяет загрузку плагина: запускает Eclipse в отдельной рабочей области
   под `xvfb` и ищет в журнале строку `AI BIRT UI plugin started`
   (контрольный запуск завершается автоматически; рабочие данные не трогаются).

Успешная установка выглядит так:

```
== 4/4 Проверка загрузки плагина (headless-запуск под xvfb)
   плагин загружен: найдено «AI BIRT UI plugin started»
```

Переменная `ECLIPSE_HOME` поддерживается и здесь.

## 3. Первый запуск

1. `/home/pka/eclipse/eclipse`
2. `Window → Show View → ИИ для BIRT → «ИИ-конструктор отчётов»`
3. Настройки подключения: `Window → Preferences → «ИИ-конструктор отчётов (BIRT)»` —
   адрес сервера, модель, ключ; кнопка **«Проверить соединение»**.

## 4. Обновление версии

Повторите `./releng/build.sh && ./releng/install.sh` при закрытом Eclipse.
Скрипт сам удалит прежние jar-ы, перезапишет записи в `bundles.info` и сбросит
кэши. Перезапустите Eclipse.

## 5. Удаление

```bash
./releng/uninstall.sh
```

Удаляются бандлы, их записи в `bundles.info` и кэши Equinox.
Пользовательские данные (`~/.ai-birt/` — настройки и журнал аудита) не трогаются.

## 6. Диагностика

**Плагина нет в «Show View».** Проверьте:

1. в журнале рабочей области (`<workspace>/.metadata/.log`) нет ли записей
   `com.aisql.birt`;
2. есть ли строки плагина в `bundles.info`:

   ```bash
   grep com.aisql.birt /home/pka/eclipse/configuration/org.eclipse.equinox.simpleconfigurator/bundles.info
   ```

3. при странностях — повторите `install.sh` (сброс кэшей) и перезапустите Eclipse.

**Предупреждение контрольной проверки.** Если при установке написано
«маркер не найден» — это не обязательно ошибка: запуск под `xvfb` зависит от
окружения. Смотрите последние строки журнала контрольной рабочей области
(`/tmp/opencode/aibirt-verify/workspace/.metadata/.log`) — скрипт их печатает.

**Eclipse не запускается.** Проверьте `eclipse.ini` — в нём должен быть прописан
Java 8 (`-vm /home/pka/opt/jdk8u504-b01/bin/java`). На новых Java (17+) Eclipse 4.7
падает с `NoClassDefFoundError: javax/annotation/PostConstruct`.

**Панель чата открылась, но запросы не уходят.** Кнопка «Проверить соединение»
в настройках покажет причину: недоступен сервер / неверный ключ / нет модели.
Ключ и адрес можно также править прямо в `~/.ai-birt/ai-birt.properties`.
