6. **Правка**: напишите «добавь в таблицу колонку с курсом» → «Правка
   отчёта…» → просмотрите список изменений → подтвердите. Ожидание: рядом

## 4. Известные особенности

- **просмотр отчёта в редакторе** (`Run → View Report`) открывается во
  **внешнем браузере** через настройки Eclipse:
  `Window → Preferences → General → Web Browser`. В скопированной с другой
  машины рабочей области там могут остаться неработающие пути (например,
  `/snap/bin/firefox`, snap-пакетов в Debian нет) — их нужно заменить на
  имеющийся браузер: `/usr/bin/chromium`, параметры `%URL%`. Путь вида
  «…/firefox» лучше не использовать: Eclipse запускает его устаревшим
  механизмом `-remote openURL(...)`, который современный Firefox не понимает.
  Для повседневной работы проще кнопка **«Просмотр…»** — она не зависит от
  этих настроек;
- **кириллица в PDF**: базовые PDF-шрифты (Times/Helvetica), которыми BIRT
  печатает отчёты по умолчанию, не содержат кириллицы — русский текст
  в PDF пропадает. Конструктор задаёт текстовым элементам шрифт
  `DejaVu Sans` (системный TrueType), а движку передаёт конфигурацию
  шрифтов (`PdfFonts`, ресурс `fontsConfig-ai-birt.xml` — каталоги
  DejaVu/Liberation) штатным `EngineConfig.setFontConfig`. Просмотрщик
  Eclipse (`Run → View Report`) создаёт движок сам и настройку не
  принимает — для него шрифты подключены в JDK:
  `/home/pka/opt/jdk8u504-b01/jre/lib/fonts` (симлинки на DejaVu; скрипт
  `releng/install-viewer-fonts.sh`) — каталог `<java-home>/lib/fonts`
  движок BIRT регистрирует сам при каждом запуске. Отчёты, собранные до
  18.10.2026, не содержат `fontFamily` — в их PDF кириллицы не будет
  (пересоберите из панели);
- **пароль базы с символами вне ASCII**: скрытое свойство BIRT 4.7
  (`odaPassword`) хранит и возвращает такие символы с потерей (каждый
  становится «?»). Пароль `agent_user` на этой машине — ASCII, поэтому
  приёмка и работа не затронуты; если пароль базы содержит кириллицу,
  панель при правке не использует прочитанное значение, а спрашивает пароль
  заново;
- **счётчик группы** (`group_count`) считается по строкам группы
  (`Total.count()` + `aggregateOn` = имя группы) — проверено рендером;
- ответ модели печатается целиком после готовности (потоковая печать — задел
  на будущее);
- закрытие/повторное открытие панели сбрасывает историю диалога (кэш
  «отчёт → спецификация» при этом сохраняется на диске);
- в перспективе «Отчёт» панель добавляется рядом с Outline; если перспектива
  была изменена вручную, место размещения может отличаться — вид всё равно
  доступен через Show View;
- ответы модели зависят от загруженной модели на сервере — при первом запросе
  модель может загружаться в память (первый ответ дольше);
- формат спецификации v0 расширяется обратно совместимо: поддержаны
  надписи, таблицы, list, grid, изображения, условия, колонтитулы и
  диаграммы (см. `docs/ADR-0001-report-spec-v0.md`,
  `docs/ADR-0002-edit-and-extensions.md`); пока не выражаются кросс-таблицы,
  произвольные extended item и скрипты событий (исполнение Java — осознанно
  выключено);
- диаграммы рендерятся только в Eclipse OSGi: standalone-приёмка
  `m2-selftest.sh` их не включает (нет OSGi-обработчика набора данных),
  для диаграмм — `aibirtSelftest` под xvfb (см. 3.4);
- в собранном отчёте пароль сохраняется в скрытом виде, как это делает сам
  дизайнер BIRT при сохранении пароля: это нужно для предпросмотра и запуска
  без повторного ввода пароля. Резервные копии `*.bak-*` содержат тот же
  скрытый пароль — храните их по тем же правилам, что и сам отчёт.
