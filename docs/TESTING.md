# Проверка плагина (этап M1)

## 1. Автоматические проверки

```bash
./releng/test.sh
```

Что проверяется (офлайн, без реального ИИ-сервера):

| Набор | Что покрыт |
|---|---|
| `JsonTest` | собственный мини-JSON: разбор (объекты, массивы, escape, \uXXXX, числа, ошибки), запись (экранирование, roundtrip), доступ по пути |
| `BirtSettingsTest` | файл настроек: значения по умолчанию, создание, запись/чтение, многострочная инструкция, незнакомые ключи, устойчивость к мусору, ASCII-экранирование значений, комментарии |
| `ChatHistoryTest` | история диалога: порядок ролей, системная инструкция, обрезка по объёму, очистка |
| `AuditLogTest` | журнал аудита: формат JSONL, поля записи, дописывание, выключение |
| `LlmClientTest` | клиент ИИ на заглушечном HTTP-сервере: успешный ответ, варианты `content`, ошибки 401/404/500, не-JSON ответ, пустой ответ, `finish_reason`, список моделей, недоступный сервер, адрес с завершающим слэшем |

Текущий результат: **133 проверки, ошибок 0** (JDK 8u504, Temurin; заглушечный
сервер — `com.sun.net.httpserver`).

## 2. Автоматическая проверка при установке

`./releng/install.sh` запускает Eclipse под `xvfb` в отдельной рабочей области
и ищет в журнале маркер `AI BIRT UI plugin started` — подтверждение, что бандлы
разрешились и UI-плагин стартовал. Последний прогон: маркер найден,
исключений в журнале контрольного запуска нет.

## 3. Ручной чек-лист (GUI, для пользователя)

1. **Запуск**. Закройте Eclipse, если он открыт, и запустите снова
   (`/home/pka/eclipse/eclipse`). В журнале рабочей области должна быть строка
   `AI BIRT UI plugin started, version 0.1.0` (`<workspace>/.metadata/.log`).
2. **Панель**. `Window → Show View → ИИ для BIRT → «ИИ-конструктор отчётов»`.
   В перспективе BIRT «Отчёт» панель стоит справа рядом с Outline.
3. **Подключение**. В настройках (`Window → Preferences → «ИИ-конструктор отчётов»`)
   нажмите «Проверить соединение» → ожидается «Связь есть…» с числом моделей ≥ 1
   и пометкой, что выбранная модель найдена.
4. **Диалог**. В панели задайте вопрос (например, «Что такое параметр отчёта в BIRT?»)
   и отправьте `Ctrl+Enter`. Ответ — по-русски, за секунды–десятки секунд;
   интерфейс во время ожидания не должен «замерзать» (можно двигать окна).
5. **Аудит**. В `~/.ai-birt/ai-birt-audit.jsonl` появляется запись с `function=chat`,
   `outcome=OK`, длительностью и размерами вопроса/ответа. Ключа в записи нет.
6. **Выключение аудита**. Снимите галочку «Вести журнал аудита», сохраните,
   задайте вопрос — новых строк в журнале нет; включите обратно.
7. **Ошибки**. Если временно испортить ключ (`llm.token`) — в чате должно появиться
   понятное сообщение про HTTP 401 и подсказку про ключ, а не техническая трассировка.
8. **Очистка**. Кнопка «Очистить чат» сбрасывает ленту; следующий вопрос уходит
   без прежней истории (по аудиту видно, что размер запроса меньше).

Замечания и пожелания по интерфейсу — присылайте: это приёмка M1,
доработки UX войдут в следующие этапы.

## 4. Известные особенности

- ответ печатается целиком после готовности (потоковая печать — задел на будущее);
- закрытие/повторное открытие панели сбрасывает историю диалога (в плане M1);
- в перспективе «Отчёт» панель добавляется рядом с Outline; если перспектива
  была изменена вручную, место размещения может отличаться — вид всё равно
  доступен через Show View;
- ответы модели зависят от загруженной модели на сервере — при первом запросе
  модель может загружаться в память (первый ответ дольше).
